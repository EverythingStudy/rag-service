# Sample Knowledge Base

这是 AI Agent 的知识库示例文档。你可以在这里存放项目文档、技术资料等，
Agent 在回答时会自动检索相关内容来增强回答的准确性。

## System Architecture

The AI Agent Runtime is built on Spring AI framework.
It connects to MCP servers for database operations and uses vector store for RAG.

## MCP Tools

- MySQL MCP: Execute SQL queries and manage MySQL databases
- Redis MCP: Interact with Redis cache and data structures
- PostgreSQL MCP: Execute SQL queries and manage PostgreSQL databases

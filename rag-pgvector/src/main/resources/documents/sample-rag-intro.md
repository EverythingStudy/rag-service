# RAG (检索增强生成) 介绍

RAG（Retrieval-Augmented Generation）是一种结合信息检索和文本生成的人工智能技术架构。

## 核心原理

RAG 的工作流程分为三个主要步骤：
1. **检索（Retrieve）**：当用户提出问题时，系统首先从知识库中检索相关文档片段
2. **增强（Augment）**：将检索到的文档片段与原始问题组合，形成增强的提示词
3. **生成（Generate）**：大语言模型基于增强后的提示词生成最终回答

## 主要优势

- **减少幻觉**：基于检索到的真实信息生成回答，大幅降低模型编造内容的风险
- **知识更新**：只需要更新知识库文档即可更新模型的知识，无需重新训练
- **可追溯**：回答可以引用具体的来源文档，增强可信度
- **成本低**：相比微调，RAG 不需要昂贵的 GPU 训练资源

## 应用场景

- 企业知识库问答
- 客户服务自动化
- 文档分析
- 法律和医疗咨询
- 技术文档辅助

## 技术组件

一个完整的 RAG 系统通常包含：
- **向量数据库**：用于存储文档的向量表示（如 PostgreSQL pgvector、Milvus、ChromaDB）
- **嵌入模型（Embedding Model）**：将文本转换为向量表示
- **大语言模型（LLM）**：基于检索结果生成回答
- **文档处理管线**：负责文档的解析、切片、向量化
